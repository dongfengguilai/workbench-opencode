一个环境同时只接收一个顶层代码任务。重复消息 ID 返回 409；先查看原会话和状态，不能盲目重发。模型不可用会显示真实错误，不切换模型。环境不可用返回 503。进程中断后查看原生工具与错误状态，不能把中断当作成功，也不承诺任意外部副作用可续跑。

范围：本项目的 Node 标准库/Git 工作流，一个固定模板、固定模型、预先授权项目。没有本地文件访问、仓库写凭据、push/自动 PR、任意服务预览、环境配置或扩展安装。项目 opencode.json/.opencode、外部自动发现配置不加载；普通源码与自然语言需求仍可正常编辑和表达。密钥、状态、缓存和依赖不进入补丁。新增二进制支持 Git binary patch；当前项目无子模块，不承诺其他项目类型。
