本机控制目录：`/home/vmware/Workspace/programs/WorkBench`。开发源码保留当前仓库，原管理员账号、数据与计数保留原路径。首次配置与启动已实际成功；PDF原生任务、普通浏览器实际成果下载、51项测试的干净复现及第二轮工作已通过，本机范围等待负责人签收。

首次在本机终端执行：

```bash
cd /home/vmware/Workspace/projects/experiments/Workbench_space/workbench-opencode
./workbench.sh dev setup --project /home/vmware/Workspace/projects/learn
```

按提示隐藏输入并确认新的工程师密码，至少 12 个字符。不要复用企业、SSH 或管理员密码，不要把密码发送到聊天中。账号固定为 `engineer-b`。

setup 先确认原生服务已停止、原磁盘未挂载，再保存权限受控的完整原 runtime 冷备。只为新工程师创建并格式化独立 1 GiB 镜像；导入授权源文件到工程师独立副本，保留源目录不动。原 Git 元数据、依赖和缓存不复制。新副本登记固定初始 commit 与原文件摘要，工程师不继承管理员项目或会话。

管理员认证配置单独转换为带随机盐的 scrypt 摘要，不覆盖原配置或改变原密码。开发工程师仅在明确的 development profile 下可用；生产启动拒绝该认证配置。原配置的 NetID 认证不自动回退。

日常维护命令：

```bash
./workbench.sh dev start
./workbench.sh dev status
./workbench.sh dev stop
```

忘记本机管理员密码时，无需旧密码，在自己的终端执行：

```bash
./workbench.sh dev reset-admin-password
```

按提示隐藏输入并确认新密码（12–1024个字符），然后用 `admin` 重新登录。不要把密码填在命令行或聊天里。本命令仅支持当前已启动的本机开发配置；检查所有原生任务空闲后，只短暂停启平台入口，撤销管理员旧登录。工程师密码及登录会话、项目文件、原生OpenCode会话、计数、模型和工作容器保持。平台连接会短暂断开，预览需要重新打开。认证配置及登录会话文件先备份到安装目录 `backups/admin-password-*/`（目录0700、文件0600）；入口健康或配置加载验证失败则恢复认证配置，不恢复或覆盖业务数据。备份含凭据，禁止提交Git。

启动恢复并核对原镜像挂载，不重新格式化。沿用 `opencode-cloud-v0` 资源名称，新工程师拥有独立模型 token、预算、guard 和网络。新工程师的 HTTPS CONNECT 网关采用既有 direct-public 出站方式，仍逐次检查全部 DNS 结果、固定公开 IP 和端口 443；原管理员网关配置保持。工作容器继续只连内部网络，不直接外连。每个原生 namespace 重新应用防火墙后启动 guard；只更新平台需要的开发配置，原生服务使用 `--no-recreate`。工作台与预览仅绑定回环端口 8444/8445，平台上游仅绑定回环 8443；浏览器不需安装根证书。

打开 `http://127.0.0.1:8444/`，默认管理员登录页可切换到本机工程师入口。绑定项目名称为 `learn`。项目的网页放在工程师副本 `web/`，预览固定端口 5173；原始授权文件保留可比较，成果通过 ZIP 和补丁交付。

重复 setup 保留密码、项目、会话和计数。未知安装内容、未知挂载文件、项目链接、任务忙碌或状态不可确认均拒绝继续。未完成 setup 的 staging 和冷备保留，不自动删除或重新初始化。旧监听进程占用端口时不替换未知进程。

如果首次安装在新磁盘挂载校验处中断，当前支持续接已验证的空磁盘检查点：

```bash
./workbench.sh dev setup --resume --project /home/vmware/Workspace/projects/learn
```

续接用内核设备号及 inode 确认 loop 对应的真实镜像，不依赖容器与宿主机的路径文字相同。它检查现有冷备 SHA-256、原磁盘未变化、项目授权摘要及已复制制品一致，然后复用原磁盘和冷备，不执行格式化。磁盘已出现项目数据或发现未知阶段时拒绝覆盖。

早期版本在这个失败步骤前只将工程师密码摘要保存在内存，进程结束后无法恢复；此情况需要在续接命令中再次隐藏输入同一密码。修正后的 setup 将摘要保存到权限 0600 的受控阶段文件，不保存明文；完成配置后移除该阶段文件。

密码配置完成后再执行真实 Qwen 任务及两轮下载验证。回滚需在任务空闲时选择原配置/上一制品，不自动用数据备份覆盖新文件或会话；工程师guard受控制品回退并恢复候选已真实通过，未恢复数据备份；详见本轮签收汇总。
